### 5. **Админ-панель (Backend)**
- ✅ API endpoints для CRUD операций с книгами:
  - `GET /api/admin/raritet-books` - получить все книги
  - `POST /api/admin/raritet-books` - создать книгу
  - `PUT /api/admin/raritet-books` - обновить книгу
  - `DELETE /api/admin/raritet-books` - удалить книгу
- ✅ Система аутентификации:
  - `POST /api/admin/session` - вход
  - `GET /api/admin/session` - проверка сессии
  - `DELETE /api/admin/session` - выход
- ✅ Защита через cookie-based сессии
- ✅ Все админские роуты проверяют авторизацию

## 🔧 Настройка и запуск

### Переменные окружения
В файле `.env`:
```
DATABASE_URL=postgresql://...
ADMIN_PASSWORD=raritet2024
```

### Команды
```bash
# Установка зависимостей
npm install

# Генерация Prisma Client
npx prisma generate

# Синхронизация БД
npx prisma db push

# Разработка
npm run dev

# Сборка
npm run build

# Запуск production
npm start
```
