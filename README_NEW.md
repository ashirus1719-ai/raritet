## 🛠️ Технические детали:

### Новые файлы:
```
app/
├── books/
│   ├── page.tsx                    # Страница каталога
│   └── [slug]/
│       └── page.tsx                # Страница книги
├── components/
│   ├── LanguageSwitcher.tsx        # Переключатель языков
│   ├── useTranslation.ts           # Хук для переводов
│   ├── BookCatalog.tsx             # Каталог книг
│   ├── BookDetail.tsx              # Детали книги
│   └── BookCover.tsx               # Обложка книги
└── page.tsx                        # Обновленная главная

lib/
├── i18n.ts                         # Переводы на 3 языка
├── books.ts                        # API для работы с книгами
├── db.ts                           # Подключение к БД
└── prisma.ts                       # Prisma Client

prisma/
├── schema.prisma                   # Схема базы данных
└── seed.ts                         # Скрипт заполнения БД
```

### Команды:

```bash
# Запуск dev сервера
npm run dev

# Заполнить базу данных книгами
npm run db:seed

# Открыть Prisma Studio (визуальный редактор БД)
npm run db:studio

# Обновить схему БД
npm run db:push

# Собрать production версию
npm run build
```
